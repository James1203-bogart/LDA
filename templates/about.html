Topic Modeling of Student Feedback

Using Latent Dirichlet Allocation (LDA)

This web-based system analyzes student feedback using Latent Dirichlet Allocation (LDA), a probabilistic topic modeling algorithm, to automatically identify dominant themes from unstructured textual data. It provides actionable insights to enhance educational quality by extracting recurring themes, evaluating topic quality, and presenting results through interactive visualizations.

System Features
  • Data Upload — Import feedback from CSV or Excel files
  • Text Preprocessing — Cleaning, tokenization, stop-word removal, lemmatization
  • LDA Topic Modeling — Automatic extraction of latent topics
  • Model Evaluation — Coherence scores, perplexity, per-topic coherence
  • Optimal Topic Discovery — Automatic search for the best k
  • Visualizations — Word clouds, bar charts, pie charts
  • Report Export — Download results as Excel or CSV
  • Manual Comparison — Compare LDA results with manually coded themes
Technology Stack

Reference

Latent Dirichlet Allocation (LDA) is a generative probabilistic topic model developed by Blei, Ng, and Jordan (2003). It assumes each document is a mixture of topics and each topic is a distribution over words; by examining patterns of word co-occurrence, the algorithm identifies clusters that represent underlying themes.
